# 登录 / 注册页重设计规格

## 背景与目标

现有认证入口由 `frontend/src/components/LoginModal.vue` 以 Element Plus 默认弹窗呈现，功能完整但视觉辨识度低、与股票研究工作台的产品气质脱节。本次只重做认证页面的表现层，目标是让登录成为研究工作台的入口，而不是孤立的表单，同时不改变现有认证流程。

## 已确认的方向

- 采用 A「信号分栏」方向。
- 品牌语气使用专业克制的文案：**把每一次登录，变成研究开始。**
- 桌面端为 44% 左侧品牌 / 市场信号区 + 56% 右侧表单区。
- 左侧使用深海蓝（沿用现有主题语义），金色仅用于品牌标记、市场信号和微弱装饰。
- 右侧使用浅色表面、清晰标签和单一主 CTA，保留登录 / 注册 tab。
- 移动端将左侧市场摘要收束为品牌标题，表单紧随其后，避免首屏滚动才能操作。

## 交互与行为边界

认证行为不变：

- 继续使用现有 `userStore.login`、`userStore.register` 和认证 API。
- 保留用户名 / 密码校验规则、错误消息、加载态、登录成功提示。
- 保留首个无效字段聚焦、登录失败后的恢复聚焦、关闭弹窗后的焦点还原。
- 保留登录成功后待办路由消费与回跳逻辑。
- 注册成功后回到登录 tab 并预填用户名。

表现层交互：

- tab 采用底部边框表示当前状态，不使用高噪声胶囊按钮。
- 每个字段使用可见 label，placeholder 只作为示例。
- 密码字段保留显示 / 隐藏能力。
- 主按钮文案为登录态「进入研究工作台」，注册态「创建研究账户」或同等短文案。
- 辅助说明提示“数据仅供研究参考，不构成投资建议”，不新增收益承诺或营销性内容。

## 响应式与可访问性

- 桌面端保持左右分栏，弹窗宽度适配当前视口。
- 小于 640px 时改为上下结构，左侧仅保留品牌标记和主标题。
- 输入与主按钮最小触控高度 44px；不禁用缩放。
- 保留 `:focus-visible` 可见焦点环，错误消息继续通过 Element Plus 的语义状态呈现。
- 遵守 `prefers-reduced-motion`，不引入阻塞表单操作的动画。
- 颜色沿用现有 tokens，正文和控件文本满足 WCAG AA 对比度目标。

## 实现边界

- 主要修改文件：`frontend/src/components/LoginModal.vue`。
- 如需少量全局样式，仅追加认证专用 class，不改动工作台其他页面的布局 token。
- 不修改后端接口、Pinia 用户状态、路由定义或数据库。

## 验证标准

- `npm run build` 成功。
- 现有 `frontend/tests/auth-validation.test.js` 通过。
- 手动检查登录和注册 tab、字段校验、密码显隐、加载态、失败聚焦、关闭后焦点还原和待办路由回跳。
- 在桌面、平板、移动宽度下确认无横向溢出，主 CTA 与输入框保持可操作。
