# 机构研究盘全站重构设计（视觉伴侣 v1）

## 1. 决策与目标

本轮采用用户在视觉伴侣中确认的“机构研究盘 v1”。唯一视觉基线为：

- `http://localhost:52765`
- `.superpowers/brainstorm/1548719-1788022175/content/institutional-workbench-all-pages-v1.html`

目标不是继续缩小 padding，而是把全站从卡片式 SaaS 后台重构为适合 A 股研究、行情比较和待处理队列的连续数据工作台。视觉稿覆盖市场、板块、雷达、自选、个股、搜索、报告列表和报告详情八个页面，正式前端必须保持相同的信息顺序、主从比例、列优先级和移动收纳规则。

核心工作流固定为：

```text
市场风险与异动 -> 板块强弱与扩散 -> 个股确认 -> 自选待处理 -> 盘后复盘
```

在不改变现有接口、路由、鉴权和数据契约的前提下，首屏必须优先回答“现在应关注什么、为什么、下一步去哪里”。

## 2. 视觉语言

- 页面底固定为 `#f6f7f7`，数据面 `#ffffff`，弱分区 `#f1f3f4`，侧栏 `#18212b`；普通模块不使用阴影。
- 主文字 `#18212b`、次文字 `#697582`、分隔线 `#dce1e5`、网格线 `#e9ecef`。
- 唯一交互蓝为 `#2b6e99`；A 股红涨 `#c83e39`、绿跌 `#18835b`、警示 `#a66c13`。
- 页面标题约 `20px`，面板标题 `13-14px`，数据正文 `13px`，辅助标签 `11-12px`。
- 数值使用等宽数字、右对齐；涨跌不只依赖颜色，同时保留正负号或文字。
- 常规内容区域圆角为 `0`，控件圆角 `4px`；只有弹窗、抽屉、菜单可使用圆角和阴影。
- 删除英文 eyebrow、欢迎语、教学式副标题和重复标题。
- 普通内容以细分隔线、表头和行 hover 建立层级；阴影仅用于搜索弹层、抽屉、对话框和菜单。

## 3. 共享界面契约

### 3.1 页面结构

```text
AppShell
├─ Navigation rail / drawer / bottom navigation
├─ CommandBar
└─ Page
   ├─ PageHeader(title, status, primary action)
   ├─ Toolbar(filters, sort, refresh, pagination)
   └─ Workspace(single / split / reader)
      └─ Panel(standard / flush / overlay)
         ├─ PanelHeader
         ├─ PanelBody
         └─ DataTable / DataList / MetricStrip
```

- `SectionPanel` 只保留布局语义，不再默认绘制四边边框、圆角或阴影。筛选器内嵌在列表工具栏，不再形成独立卡片。
- 页面标题行 `44px`，工具栏 `40px`，表头 `32px`，常规桌面数据行 `40px`，带副字段的数据行 `44px`。
- 常用间距只使用 `4 / 8 / 12 / 16px`；不允许卡片套卡片、行卡片化或用阴影建立普通层级。
- 数字统一使用等宽字形和右对齐；涨跌除颜色外必须保留 `+/-`。

### 3.2 响应式

- `>=1280px`：`168px` 完整侧栏与最大化工作区。
- `1024-1279px`：`64px` 图标轨道，保留内容宽度。
- `768-1023px`：顶栏与抽屉；自选使用精简列；板块详情使用右侧检查器。
- `<768px`：`48px` 顶栏与可达的一级导航；一行一个标的，低频操作进入更多菜单或抽屉。
- 手机分页只显示上一页、页码状态和下一页，不渲染完整页码器。

## 4. 页面信息架构

### 4.1 市场概览

首屏顺序为交易状态、市场脉冲、板块强弱、自选待处理。三大指数与市场宽度组成六格连续指标带；主工作区按 `2:1` 展示板块表和待处理检查器；AI 摘要固定为底部单行次级带。

### 4.2 板块发现

行业/概念切换、搜索、排序和分页处于同一工具栏。主区为 `58:42` 连续板块排行表与成分股检查器；移动先显示排行，详情进入抽屉或独立上下文。列表与详情保持路由深链和筛选上下文。

### 4.3 机会雷达

顶部为筛选工具栏和四格结果摘要；主区为 `30:70` 的板块信号索引与候选股票表。雷达只负责从板块收敛候选，完整板块核查仍由板块页负责。移动端优先候选股票表，保留股票、最新价、涨跌、信号和加入自选。

### 4.4 我的自选

分组、总数、刷新和添加位于单行工具带。待处理信号只保留摘要和前三条，不得压在主表之前形成大块卡片。主表核心列为股票、现价涨跌、成本收益、信号、备注、更新时间和更多操作；平板精简列，移动端一行一只标的。

### 4.5 个股详情与搜索

个股页顶部是一条身份与价格带，下方按 `72:28` 展示 K 线和事实/研究检查器；只保留一份行情事实。搜索页让输入、结果计数、排序和分页紧邻结果表，最近搜索只作辅助。

### 4.6 报告

报告列表优先显示日期、结论、风险、重点股票数和完成时间。详情页先展示今日结论、风险和关联股票，再展示正文；正文维持 `60-68ch` 阅读宽度。关联股票必须能回到个股上下文。

## 5. 范围与边界

本轮修改前端样式、页面模板、基础组件和必要的前端契约测试。不修改后端 API、数据库、共享数据模型、依赖和根构建配置；不删除现有文件，不执行 commit、push 或 merge。现有三套主题基础设施可以保留兼容，但用户界面只呈现已确认的浅色研究盘，不再展示品牌换肤入口。

已有其他 Agent 或用户改动必须增量保留。若实现时发现新增业务页面或组件，先完成只读盘点，再按本设计补齐视觉接入，不擅自改变业务行为。

## 6. 验收标准

- 主要页面不再出现英文 eyebrow、常规阴影卡片、筛选卡和重复行情事实。
- 桌面行情表可连续扫描，常规数据行固定为 `40px`，数值等宽并右对齐。
- `1440x900` 首屏能看到主表或核心图表，不需要先滚过多个说明卡片。
- `1024x768` 不出现完整侧栏挤压九列表格；`390x844` 和 `360x800` 无页面横向溢出。
- 市场、板块、自选、个股、搜索、报告的加载、空、错误和分页状态仍可用。
- 前端全量测试、生产构建、`git diff --check` 和 `52764` 关键路由检查通过。
- 在浏览器能力可用时完成 `1440x900`、`1024x768`、`390x844`、`360x800` 截图验收；不可用时必须明确记录限制。
