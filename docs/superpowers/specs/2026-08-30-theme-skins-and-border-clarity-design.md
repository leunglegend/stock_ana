# 研究台多皮肤与边框可读性设计

## 目标

在不改变现有业务接口、路由和页面信息架构的前提下，提供三套可持久化的研究台皮肤，并提升工作面边框的可见度，让数据区域更容易扫描。

## 主题方案

- `ocean`（默认）：深海蓝侧栏、冷灰页面、蓝色主操作，作为首次访问和非法主题值的回退。
- `jade`：墨绿侧栏、浅绿灰页面、青绿色主操作，适合长时间研究。
- `charcoal`：炭黑侧栏、暖白页面、朱砂主操作，作为可选的报告/编辑台风格。

主题只通过 `:root[data-theme]` 覆盖语义 Token。组件继续消费 `--surface-*`、`--text-*`、`--border-*` 和状态 Token，不新增组件级固定颜色。

## 交互入口

桌面命令栏展示主题按钮和色板下拉菜单；移动端隐藏低频按钮，将三套皮肤放入“更多”菜单。选择立即更新 `document.documentElement.dataset.theme`、写入现有 localStorage key，并派发现有主题变更事件，K 线图等监听者无需改动。

## 边框层级

- 页面/工作区外框：`--border-default`，需要明确圈出主要工作区域。
- 数据行和分组分隔：`--border-subtle`，保证连续性但不抢夺内容注意力。
- 交互选中和焦点：主题色左边线或 focus ring。
- 普通面板不恢复阴影；仅弹层继续使用提升阴影。

## 验收标准

1. 三套主题均可从命令栏选择，刷新后保持选择，非法值回退 Ocean。
2. 桌面、平板、移动入口均可操作，按钮满足最小触控尺寸并有 aria-label。
3. 主要页面工作区外框和数据行分隔线在三套主题中均清晰可辨，无组件级 raw color 回归。
4. 现有前端契约测试、后端测试、生产构建和四档视口审计继续通过。
