# 前端多主题配色系统设计

## 1. 目标

改善股票研究工作台颜色层次，在不改变页面结构、业务流程和后端接口的前提下，提供三套全站主题：

- `ocean`：深海蓝与金色信号，作为默认主题。
- `jade`：墨绿与琥珀，作为可选主题。
- `charcoal`：炭黑与朱砂，作为可选主题。

三套主题均保持专业、高密度、低装饰的研究工作台风格。红色始终表示上涨，绿色始终表示下跌；错误、警告等功能色不因主题改变含义。

## 2. 范围

本次包含：

- 全局品牌色、页面表面、侧栏、面板、边框、文本、链接、焦点环、AI 区域与图表辅助色。
- 顶部命令栏的主题切换入口。
- 桌面端和移动端主题选择交互。
- 浏览器本地持久化、启动恢复及非法值回退。
- ECharts 在运行时切换主题后的重绘。

本次不包含：

- 暗黑模式或跟随操作系统模式。
- 用户账户服务端主题同步。
- 页面布局、业务组件、接口或数据结构调整。
- 改变 A 股红涨绿跌语义。

## 3. 技术方案

根元素使用 `data-theme` 标识当前主题：

```html
<html data-theme="ocean">
```

现有组件继续消费 `tokens.css` 中的语义变量。默认 `:root` 定义 `ocean`，`[data-theme="jade"]` 与 `[data-theme="charcoal"]` 只覆盖会随主题变化的变量，避免复制间距、字体、圆角和通用状态色。

主题值限定为 `ocean | jade | charcoal`。应用初始化时读取本机存储；缺失、损坏或不支持的值统一回退 `ocean`。

## 4. 色彩职责

### 4.1 跨主题稳定

- `--color-up-*`、`--text-positive`：A 股上涨红。
- `--color-down-*`、`--text-negative`：A 股下跌绿。
- 错误、警告和成功语义色。
- 文本对比度、键盘焦点可见性要求。

### 4.2 随主题变化

- `--color-primary-*`：品牌及主要操作色。
- `--color-accent-*`：金色、琥珀或朱砂强调色。
- `--surface-page`、`--surface-canvas`、面板表面与侧栏表面。
- 默认边框、强调边框、链接与焦点环。
- AI 摘要表面和非涨跌类图表系列色。

主题不会只替换一个主色。页面背景、侧栏与内容面板之间必须形成可感知但克制的明度或色相差，解决当前大面积灰白表面过于接近的问题。

## 5. 组件与状态

新增轻量主题模块，职责为：

- 声明主题元数据，包括键、中文名称和预览色。
- 读取、校验、应用和持久化主题。
- 向组件暴露当前主题及切换方法。
- 应用主题后派发全局 `app-theme-change` 事件。

顶部命令栏新增调色盘图标按钮：

- 使用现有 Element Plus 图标和下拉菜单。
- 按钮提供 `aria-label` 和 tooltip。
- 菜单展示主题名称、色板预览及当前选中状态。
- 未登录与已登录状态均可操作。
- 移动端保持至少 `44x44px` 触控目标。

## 6. 启动与切换流程

应用启动：

1. 从 `localStorage` 读取主题键。
2. 校验主题；无效时使用 `ocean`。
3. 在 Vue 页面渲染前写入根元素 `data-theme`。
4. 组件读取同一主题状态。

用户切换：

1. 用户在命令栏选择主题。
2. 主题模块更新根元素属性和响应式状态。
3. 将合法主题键写入 `localStorage`。
4. 派发 `app-theme-change`。
5. K 线等 ECharts 组件重新读取 CSS Token 并重绘。

存储失败不会阻止当次换肤；刷新后回退到可读取的主题或默认主题。

## 7. 无障碍与视觉约束

- 正文与背景对比度至少达到 WCAG AA 4.5:1。
- 大号文字和非文本控件至少达到 3:1。
- 主题选中状态同时使用图标或文字标记，不只依赖颜色。
- 聚焦状态在三套主题中均清晰可见。
- 不添加渐变、装饰性光斑或大面积营销式色块。
- 色彩只增强信息层级，不替代涨跌符号、标签或数值。

## 8. 验证与验收

- 默认首次访问使用 `ocean`。
- 三套主题均可从顶部命令栏切换，页面无需刷新。
- 刷新后恢复上次合法选择。
- 非法或损坏的存储值回退 `ocean`，页面不报错。
- 切换后侧栏、页面背景、面板、按钮、链接、AI 区域和图表同步更新。
- 红涨绿跌在三套主题中保持不变。
- 在 `360x800`、`390x844`、`768x1024`、`1440x900` 下无按钮遮挡、文本溢出或非预期横向滚动。
- 通过前端构建与相关自动化测试，并用浏览器截图检查三套主题的代表页面。
