# 全站重点数字科技感增强设计

## 目标

在全站统一放大重点数字并增强语义颜色，让价格、涨跌幅、指标、统计数量和雷达摘要更易扫描，同时保持现有布局、数据格式、正负号、主题皮肤和移动端响应式行为不变。

## 视觉方向

采用“科技终端”方向：重点数字使用等宽数字、较高字重和更明确的主题/涨跌色；标签、单位和辅助文案保持较低层级。数字只增强信息层级，不添加大面积渐变、装饰性动画或阴影。

## 组件策略

- `MetricCell`：作为指标数字基线，主值提升到 21–22px；正负 tone 使用 `--text-positive` / `--text-negative`，中性使用 `--text-primary`。
- `PriceDisplay`：价格主值整体提升一档；涨跌金额和百分比保持较小但使用明确语义颜色。
- `PercentageDisplay`：`md` 与 `lg` 提升字号和字重，沿用正负号与红绿语义。
- 页面专用统计：雷达摘要、看板统计、报告数量等仅在已有“value/metric/total”选择器上提升层级，继续消费主题 Token。

## 约束

- 不改变 API、数据格式、路由、组件 props 或页面布局。
- 不使用页面级 raw color；颜色全部来自主题语义 Token。
- 移动端数字不得导致横向溢出，长数字继续使用现有截断/换行策略。
- 颜色不是唯一含义，正负号和文本仍然保留；焦点、错误和无障碍对比度不降低。

## 验收标准

1. 全站共享重点数字比当前更大、更醒目，科技感来自字形、字号、字重和主题色组合。
2. 上涨/下跌/中性三种状态在 Ocean、Jade、Charcoal 三套主题中均保持一致语义。
3. 首页、个股、板块、雷达、自选、搜索、报告页面无明显溢出或布局跳动。
4. 前端契约测试、生产构建和 `git diff --check` 通过。
5. `52766` 对比页与 `52764` 正式入口均能看到更新后的字号和颜色。
