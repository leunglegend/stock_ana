# 打赏入口设计轮 · 候选方案概览(评审用)

> 2026-09-04 · 智能股票分析平台「点赞/打赏」入口
> **已锁定前提**(三方案共用,评审按此打分):
> - 文案人设 = **股东情怀版(适度)**:用户=股东,打赏=给平台/AI「增资 / 信仰充值」;只玩文案与轻交互,不做金额档位/积分/排行榜
> - 入口 = **全站常驻**(顶栏或页脚)
> - 支付 = **微信 + 支付宝个人收款码**(作者自贴码),**无后端资金流、无到账检测、无商户 API、不伪造支付成功**
> - 颜色语义:本产品红涨绿跌(红=涨 `--color-up-500`,绿=跌 `--color-down-500`),「绿/跌/打工」是安全自嘲对象
> - 红线:不承诺收益、不诱导未成年人、不把打赏说成投资回报、不出现「募捐/慈善/公益」

三份完整方案文档见同目录 `01 / 02 / 03`。以下是每套的浓缩要点。

---

## 方向一 · 页脚静默增资(最克制)
**文件**:`01-方向一-页脚静默增资.md`

**一句话**:在最不显眼的地方给一句最像注脚的话——全站页脚放一行与免责声明同级的股东小字,点了才知道这是一次不上市的「A 轮融资」。

- **关键现状发现**:**当前全站没有页脚**(合规声明只藏在登录框里),所以本方向=先补一个真正的站级页脚(把「数据仅供参考、不构成投资建议」落到每个页面底部),再在页脚里放一个安静的词
- **入口**:页脚右侧一行 `股东可顺手增资 ↗`,与免责声明同色同字号(text-tertiary),hover 才显色;移动端用同一页脚(无底栏遮挡、滚动可达),共用一个入口
- **弹层**:el-dialog「A 轮(不上市)融资」面板——主句「本台 A 轮融资开放——本轮唯一股东:你。」+ 副句讲清个人维护自费 + 微信/支付宝双码并排「金额随缘」+ 掩码收款方信任小字 + 合规小字 + 按钮「继续看盘」;「转账成功后无需操作,心意已收到」诚实替代伪造回调
- **克制策略**:零主动打扰(无弹窗/红点/计数/状态)、单入口、关闭即静默、无 dismiss 状态
- **技术落点**:新增 `SiteFooter.vue` + `TipDialog.vue` + `Layout.vue` sticky-footer 小改 + 2 张作者码图;零后端/零 store/零路由,约 0.5 人日
- **给评审的亮点**:①入口只是一行注脚,纯静态零状态最克制 ②顺手补了本就该有的合规页脚,「顺带感」不像在要钱 ③金额与"反馈"都被诚实处理
- **给评审的顾虑**:①「克制」与「可发现」矛盾——页脚入口注定点击率极低,想要"能运转"可能要靠方向三接住 ②个人收款码公网信任 + 作者只能人工对账、无到账可见性

## 方向二 · 顶栏信仰充值(显性但自克制)
**文件**:`02-方向二-顶栏信仰充值.md`

**一句话**:顶栏右侧一枚「低调但一眼可见」的充值胶囊,点开是一张股东情怀版「增资」打赏卡。

- **入口落点**:真正的全站顶栏 = `Layout.vue` 里的 `CommandBar.vue` 右簇(铃铛左侧、贴近头像);桌面为文字胶囊「信仰充值」(金色 `Coin` 图标+描边),<1024 收成纯图标,移动端 44px 触控图标(Plan B:收进 ⋯ 更多菜单)
- **三级声量状态机**(localStorage `tip_pay_meta`):未点开=文字胶囊 → 点开过一次=自动降级纯图标(不隐藏只降噪)→ 主动「暂时收起」=隐身 30 天
- **打赏卡**:eyebrow「股东专线 · 增资入口」+ 主句「给『析股研究台』充点信仰,行情绿了我们也不慌。」+ 副句 + 双码并排「金额随缘,由你亲手输入」+ 轻按钮「下次一定」/「暂时收起这个入口」+ 两行合规脚注(含「『增资/入股』只是玩梗」澄清与未成年人勿打赏)
- **技术落点**:`CommandBar.vue` 插一行 `<TipPayEntry />` + 新增 `TipPayEntry.vue`/`TipPayDialog.vue`/`tipPayState.js` + 2 张码图;零后端零新依赖
- **给评审的亮点**:①「点开即降级」的自克制状态机把"常驻但不骚扰"落成可执行形态,成本一个 localStorage 键 ②合规话术(不承诺收益/未成年人)织进可见文案而非角落小字 ③改动面收敛、全部复用现有 el-dialog 与 design tokens
- **给评审的顾虑**:①顶栏右簇是高频区(搜索/通知/账户),常驻按钮稀释密度,768–1024 平板可能偏挤 ②双码静态+无到账检测=无反馈闭环,「增资/入股」梗有被个别用户读成真有回报的歧义

## 方向三 · 点赞为股 · 两段式(对免费用户最友好)
**文件**:`03-方向三-点赞为股两段式.md`

**一句话**:先给零成本、能点亮、有仪式感的「股东表达」(点赞=投一票),再把打赏包装成「顺带增资」——不逼捐。

- **动线三步骤**:①顶栏点赞图标(免费,一点点亮金色 warning,弹出确认卡,不弹打赏)→ ②确认卡内浮现「顺带增资?」轻引导 + 幽灵拒绝出口「先不了,白嫖也是股东权益。」→ ③进打赏卡(双码+主句「研究不收费,服务器要养;各位股东,量力增资。」)
- **防打扰是机制性的**:自动「增资邀请」只在"刚点赞"这个用户主动动作后出现,且终身最多 3 次/每天最多 1 次/可永久关闭「以后别再提增资」;无任何页面加载/定时/路由弹窗、无红点、无数字勾引
- **诚实边界**:UI 永不显示「N 人已赞」统计(无后端,任何计数都是单浏览器幻觉,既骗用户也骗作者);文案只用「单数、对你一个人说」的股东话术;不伪造支付成功,真实到账才是唯一真数
- **点赞态**:localStorage `stock_support_v1`(沿用 `stock_` 前缀),Pinia store + persistence 帮助函数;换设备丢失、属"本地彩蛋"会显式告知
- **技术落点**:新增 `SupportButton.vue` + `TipSupportDialog.vue` + `support.js`/`supportPersistence.js` + `supportCopy.js`(集中改稿点)+ 2 张码图,`CommandBar.vue` 插 2 行;约 500–650 行,零后端
- **给评审的亮点**:①两段式+股东梗+体面拒绝出口=对免费用户最友好的打赏结构 ②防打扰是设计出来的(三重闸门) ③诚实边界写进产品(不造假数、不伪造到账),技术小而干净
- **给评审的顾虑**:①完全不做计数,作者端连"点赞量"都看不到,数据回报≈0,长期可能"做了个寂寞" ②金色点亮态与「加入自选收藏」的 warning 金语义靠色相拉不开,用户可能混淆「我收藏过」与「我点过赞」,需视觉区隔拍板

## 给评审的特别说明(评审视角映射)

本功能是**作者变现/激励**功能,不是行情分析功能。评审时请把各自的维度**映射到"打赏该不该要、怎么要才得体"**上来:

- **ux-reviewer(体验官)**:重点评入口**可发现 vs 打扰**的平衡、两段式路径步数、弹窗与现有 Dialog 的一致性、打赏后"无反馈"的降级体验
- **genz-reviewer(年轻股民)**:重点评三个方向里哪个更像 2020s 产品的打赏姿势(吃相好看)、移动端是否成立、股东梗有没有"愿意当谈资转发"的话题感
- **pro-investor-reviewer(专业视角)**:本维度映射为——打赏入口/股东梗会不会**损害平台作为研究工具的公信力**(个人收款码、玩梗要钱的观感 vs 严肃分析);数据与统计是否**诚实**(假计数/伪造到账是误导);**合规边界**(不承诺收益、不诱导未成年人、避免被误读为荐股收费);以及未来接真实打赏/真实计数的**扩展性**

三套方向得分仅供主会话汇总,最终由用户拍板。
